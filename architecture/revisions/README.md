# Revision snapshots

Immutable, content-hashed snapshots, one directory per revision, named `<architecture-id>-rN`. See [../README.md](../README.md#sealing-a-revision).

Files here are hashed byte for byte (see [.gitattributes](../../.gitattributes)); never normalize line endings or reformat them.

Worked examples live in `scripts/tests/fixtures/` and are test data only. They are not real architecture and carry no authority.
